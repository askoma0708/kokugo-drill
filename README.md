# 国語科 学習指導要領ドリル

小学校国語科（平成29年告示 学習指導要領）の教員採用試験対策ドリルです。
`index.html` 1ファイルで動作し、GitHub Pages でそのまま公開できます。

## 主な機能（v2）

| 分類 | 機能 |
| --- | --- |
| アカウント・ログイン | メールアドレス＋パスワード、または Google アカウントでログイン。記録はクラウド（Firebase）に自動保存され、再起動後や別の端末でも続きから学習できる（下記の初期設定が必要） |
| この端末だけで使う | ログインせずに使うモード。記録はブラウザ（localStorage）に保存。あとからアカウントへ引き継ぎ可能 |
| 学習履歴 | 問題ごとの正誤・復習予定、日別の解答数、セッション履歴。JSON で書き出し／読み込み（端末移行・バックアップ） |
| ゲーミフィケーション | XP・レベル・称号、連続正解コンボ、連続学習日数（ストリーク）、1日の目標と達成ボーナス、実績バッジ17種、効果音・紙吹雪 |
| 間隔反復 | ライトナー方式。正解で復習間隔が 1→3→7→14→30日 と伸び、不正解で1日後に戻る。「今日の復習」を自動作成 |
| 学習プラン | 今日の復習／おまかせ10問／新しい問題／苦手克服／模擬テスト（20問・時間計測・解答は最後）／自由演習（領域・学年・習熟度で絞り込み） |
| 学習効果 | 不正解の問題はセッション末尾で再出題、解答後に本文（空欄を埋めた全文）を表示、「まぐれ」申告で早めに復習、問題ごとの自分用メモ、穴埋め式のヒント |
| 記録画面 | 学習カレンダー（16週）、直近7日の解答数、領域別の習熟度、履歴表 |
| 一覧 | 全問を「答えを隠して」読める暗記用ビュー。絞り込んだ問題だけを演習可能 |
| 操作性 | キーボード操作（1〜3で選択、Enterで次へ）、穴埋めの表記ゆれ吸収（全角/半角・空白・読点）、ダークモード、スマホ対応 |

## ログイン機能の初期設定（管理者が1回だけ行う）

クラウド保存には Google の [Firebase](https://firebase.google.com/)（無料の Spark プラン）を使います。
設定するまでは、従来どおり「この端末だけで使う」モードで動きます。
画面の表記は Firebase の更新で変わることがあります。

1. **プロジェクトを作る**
   [Firebase コンソール](https://console.firebase.google.com/) に Google アカウントでログインし、
   「プロジェクトを作成」→ 名前（例：`kokugo-drill`）を入力して作成します。Google アナリティクスはオフで構いません。
2. **ウェブアプリを登録する**
   プロジェクトのトップで「ウェブ」（`</>` のアイコン）を押し、アプリのニックネーム（例：`drill`）を入れて登録します
   （Firebase Hosting の設定は不要）。表示される `const firebaseConfig = { ... };` をコピーしておきます。
3. **ログイン方法を有効にする**
   「構築」→「Authentication」→「始める」→「ログイン方法」タブで
   - 「メール / パスワード」を有効にして保存
   - 「Google」を有効にし、サポートメールを選んで保存

   続けて「設定」タブ →「承認済みドメイン」→「ドメインを追加」で `askoma0708.github.io` を追加します。
4. **データベースを作る**
   「構築」→「Firestore Database」→「データベースを作成」。エディションを聞かれたら「Standard」、
   ロケーションは `asia-northeast1（Tokyo）`、モードは「本番環境モード」で作成します。
   作成後「ルール」タブを開き、このリポジトリの [`firestore.rules`](firestore.rules) の内容に全部置き換えて「公開」します。
   （本人だけが自分の記録を読み書きできるルールです。）
5. **設定をアプリに書き込む**
   [`firebase-config.js`](firebase-config.js) の `null` を、手順2でコピーした `{ ... }` の部分に置き換えて保存（コミット）します。
   1〜2分でサイトに反映され、ログイン画面が表示されます。

`firebaseConfig` の値は公開しても安全です。データはセキュリティルールで守られます
（参考：[Firebase の API キーについて](https://firebase.google.com/docs/projects/api-keys)）。
無料枠は Firestore の読み取り 1日5万回・書き込み 1日2万回などで、Spark プランでは超えても課金されず、その月は止まるだけです
（参考：[Firebase の料金プラン](https://firebase.google.com/docs/projects/billing/firebase-pricing-plans)）。

## 注意

- 「この端末だけで使う」モードの記録は、プライベートウィンドウ、終了時にデータを消す設定のブラウザ、
  再起動で元に戻る共用パソコンなどでは消えます。継続して使う場合はアカウントでのログインをすすめてください。
- 共用パソコンでは、ログイン画面の「ログインしたままにする」のチェックを外し、終わったらログアウトしてください。
- 問題文は学習用の要約です。全50問を『小学校学習指導要領（平成29年告示）解説 国語編』（文部科学省、平成29年6月）と照合済みです
  （本文は同解説に引用されている箇所で確認）。試験前には最新の原典も確認してください。
